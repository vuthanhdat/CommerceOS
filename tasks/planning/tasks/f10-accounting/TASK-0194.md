## Objective
Post approved GRNI/AP/PPV/supplier-payment and inventory-adjustment entries from authoritative producer facts without rewriting operational history.

## Scope
Goods receipt cost acceptance -> Dr Inventory/Cr GRNI; SupplierInvoice -> Dr GRNI/Cr AP plus approved PPV; SupplierPayment -> Dr AP/Cr Cash; adjustment decrease/increase -> loss/gain postings; valuation updates; source dedupe.

## Out of scope
Bank execution, tax/freight/PO discount accounting, foreign-table lookup.

## Inputs
PD-022/024/029 and Procurement/Inventory facts.

## Expected changes
Accounting consumers/valuation/journal tests.

## Implementation steps
Define required fact payloads, implement per-source posting functions and valuation effects, preserve invoice variance evidence, add duplicate/out-of-order/invalid amount tests.

## Acceptance criteria
- [x] Confirmed receipt cost posts Inventory/GRNI once.
- [x] Invoice clears GRNI to AP and approved difference posts PPV rather than changing receipt history.
- [x] SupplierPayment clears AP to Cash once and represents attested evidence only.
- [x] Inventory adjustment postings use approved valuation basis and never Catalog advisory cost.
- [x] Duplicate facts do not duplicate posting/value effects.
- [x] All entries balance and preserve source provenance.

## Verification
Unit/persistence/consumer replay/LocalStack integration/harness.

## Architecture / security / reliability / observability / local runtime
Accounting owns value; producer facts carry required evidence, not table pointers.

## Risks and edge cases
Late invoice variance, correction receipt facts, adjustment increase valuation basis.

## Open questions
If a missing approved valuation basis appears, stop rather than infer Catalog cost.

## Completion report
Confirmed receipt, invoice (including approved PPV), supplier payment and stock-adjustment consumers use only fact payload evidence. Missing approved increase cost produces `NeedsAttention` rather than using Catalog cost.
