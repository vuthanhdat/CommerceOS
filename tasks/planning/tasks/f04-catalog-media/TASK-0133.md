# TASK-0133 — Implement Files/Media upload boundary and Product media association

## Metadata
- Feature: F04
- Status: Backlog
- Priority: P1
- Requirement IDs: REQ-MED-001
- Depends on: TASK-0130
- Blocks: rich public Product media
- Estimated complexity: L
- Last updated: 2026-08-13

## Objective
Provide Tenant-owned merchant uploads through a FilesMedia capability and let Catalog associate only validated same-Tenant managed assets.

## Scope
FilesMedia metadata ownership; upload/init/finalize/read/delete-or-retire policy appropriate to MVP; S3-style LocalStack object boundary; media metadata/content validation; Catalog association/order/display metadata; tenant isolation.

## Out of scope
External image hotlink/copy, PDI image import, CDN real-cloud setup.

## Inputs
Catalog media policy, technical baseline, S3 capability mapping.

## Expected changes
FilesMedia module, object-storage adapter/CDK and Catalog contract integration after inspection.

## Implementation steps
Define project-owned storage port and asset identity; implement LocalStack S3 adapter; validate upload metadata/content limits; enforce Tenant ownership in association; add cleanup/failed-upload tests.

## Acceptance criteria
- [ ] Public Product media references only CommerceOS-managed merchant uploads.
- [ ] Cross-Tenant asset association/read is denied/non-disclosing.
- [ ] Catalog owns association/publication decision; FilesMedia owns asset identity/metadata.
- [ ] External source URLs never become public media automatically.
- [ ] Object storage is reproducibly provisioned/reset in LocalStack.

## Verification
Unit/contract/S3 integration/tenant-isolation/CDK/harness.

## Architecture / security / reliability / observability / local runtime
Validate content/size/type defensively; no unsafe secrets; object lifecycle failures diagnosable.

## Risks and edge cases
Orphan upload cleanup and partial upload/finalize.

## Open questions
Exact retention/deletion semantics should preserve any referenced/audit evidence; keep task MVP-minimal.

## Completion report
Record storage/association tests and limitations.
