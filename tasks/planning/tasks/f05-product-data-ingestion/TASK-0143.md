## Objective
Turn normalized source evidence into explicit Ready/Approved/Applied/Rejected/Superseded candidate review without giving PDI authority over canonical Catalog.

## Scope
ImportCandidate lifecycle; diff/field review query; Owner/Admin approval/reject; source freshness/supersede; call Catalog apply contract; mark Applied only after Catalog accepts; provenance.

## Out of scope
Automatic application, source price automatically becoming sell price, external description/image republication.

## Inputs
PD-040, Catalog apply contract.

## Expected changes
PDI Application/persistence/back-office UI contracts/tests; exact UI area after inspection.

## Implementation steps
Implement candidate state/revision/idempotency, review DTO, approval/reject, Catalog call and success transition, stale/newer candidate behavior.

## Acceptance criteria
- [ ] Ready candidate is source evidence only.
- [ ] Only authorized merchant review may approve/reject.
- [ ] Approved does not imply Catalog changed.
- [ ] Applied occurs only after Catalog accepted the explicit mutation.
- [ ] Rejected/Applied/Superseded are terminal history; replay does not duplicate apply.
- [ ] Source provenance remains traceable.

## Verification
