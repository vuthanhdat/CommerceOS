## Objective
Run manual crawl work through bounded durable queue processing with raw evidence retention, normalized snapshots, retry/rate limits and actionable DLQ behavior.

## Scope
Work outbox/queue/DLQ; worker; per-source concurrency/rate/jitter; retry classification; S3 raw payload retention; normalized snapshot/version/hash; parser failure taxonomy; observability and poison handling.

## Out of scope
Unbounded worker scaling, bypassing 403/CAPTCHA/policy restrictions, scheduled refresh.

## Inputs
PDI architecture/doc, ADR-012/queue rules, adapter from TASK-0141.

## Expected changes
PDI worker/infrastructure/CDK/LocalStack tests.

## Implementation steps
Define stable work message/id; provision queue/DLQ/object storage; implement bounded worker and retries; persist raw/normalized evidence; configure retention; test duplicates/transient/permanent failures/DLQ.

## Acceptance criteria
- [ ] Required work survives source commit and duplicate delivery is safe.
- [ ] Per-source concurrency/rate limits cap external requests.
- [ ] Transient failures retry boundedly; stable policy/parser/404 classes do not loop blindly.
- [ ] Exhausted poison work reaches DLQ with replay identity intact.
- [ ] Raw payload retention is bounded and normalized snapshot is immutable/provenanced/versioned.
- [ ] No test requires repeated live external calls.

## Verification

## Risks and edge cases

## Open questions
