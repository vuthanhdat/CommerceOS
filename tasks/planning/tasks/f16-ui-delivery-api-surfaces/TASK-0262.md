## Required UI behavior
Business: DisplayName, TimeZoneIana, Tenant status/revision; permitted profile edit. Storefront: slug/public URL/current availability and approved configuration flow. Team: members plus invitations, role/status/revision/expiry; invite/resend/revoke/change role/status. Subscription: current condition/plan version/period/entitlements/pending downgrade/cancel renewal, available plans and lifecycle actions. Notifications: unread/read/ack state and actions. Audit: timestamp/action/entity/source/correlation/safe evidence list for authorized users.

## Acceptance criteria
- [ ] Navigation/actions adapt to current server-presented capability and Tenant status without becoming authorization authority.
- [ ] Suspended/read-only merchant state does not present mutation success paths that backend will deny.
- [ ] Team UX prevents obvious last-owner/admin violations before submit while still handling server conflict.
- [ ] Invitation credential handling does not persist or log secret material unnecessarily.
- [ ] Subscription screen shows actual Entitlements and pending/blocked states rather than inferring capability from plan label.
- [ ] Notification acknowledge is visibly separate from resolving the originating operational issue.
- [ ] Audit screen is not visible/actionable to unauthorized roles and safely handles large evidence lists.
- [ ] Loading/empty/error/conflict/limit/payment-unknown states are usable.
- [ ] Responsive/accessibility/browser tests and full harness pass.

## Verification
Backoffice component/browser tests for profile, team invitation/member change, subscription lifecycle, notification read/ack and audit access; frontend build; full harness.

## Architecture / security / reliability / observability / local runtime
UI keeps merchant and Platform Admin authority separate. No secrets or sensitive Audit/Invitation payloads in browser logs. LocalStack-only backend runtime.

## Risks and edge cases
Tenant suspension mid-session, membership changed in another tab, invitation expiry, billing OutcomeUnknown, downgrade blocked by usage, long audit list.
