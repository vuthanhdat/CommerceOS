## Out of scope
Automatic guest-to-customer matching/creation, shopper authentication, inferred identity merge, marketing automation.

## Inputs

## Expected changes

## Implementation steps
Confirm minimal Customer domain fields/commands before code, implement module/table and tenant-scoped queries, explicit link semantics if approved, protect Order snapshot immutability.

- [ ] Guest checkout remains valid without Customer record.
