## Completion report
Completed 2026-08-14. CDK now provisions the ADR-010 STANDARD state machine with Success/Declined/Timeout branches, a reconciliation wait, and an explicit retry/catch path to `NeedsAttention`. LocalStack 4.8.1 instance 0017 executed `Success -> Allocated`, `Declined -> AwaitingPaymentRetry`, and `TimeoutAfterCommit -> NeedsAttention`; a duplicate `StartExecution` name was rejected. Owner effects remain verified by the existing `OrderWorkflowCoordinatorTests`, which exercise Inventory, Payments, and Sales contracts directly; the LocalStack workflow verifies the durable control-flow capability and never writes owner tables. LocalStack requires `stepfunctions` in the configured service list. The AWS-SDK Step Functions integration used solely for the recovery probe is emulator-control-flow evidence, not a substitute for production task adapters or AWS-equivalence.
